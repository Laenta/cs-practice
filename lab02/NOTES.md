1
Рабочая папка - папка где находятся файлы проекта и с которой работает
гит
Индекс- промежуточная область, куда добавляются изменение перед
коммитом
Коммит - сохраненная версия изменений в гит с описанием того что было
изменено

2
Git и GitHub - гит это инструмент для контроля версий, а гитхаб платформа в интернете для работы с ним

git diff - Сравнивает рабочую папку и Индекс
git diff --staged - сравнивает индекс и последний коммит

3
git status - показывает текущее состояние гит
git diff - показывает изменения между рабочей папкой и индексом
git diff --staged - показывает изменения между индексом и последним коммитом

Ветки - отдельная линия разработки проекта. Позволяет менять код не затрагивая основную ветку
Слияние - объединение изменений в разных ветках
После нового коммита - Ветка сдвигается на новый коммит, новый коммит становится последним, предыдущие коммиты остаются в истории
