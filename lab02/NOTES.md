Рабочая папка - папка где находятся файлы проекта и с которой работает
гит
Индекс- промежуточная область, куда добавляются изменение перед
коммитом
Коммит - сохраненная версия изменений в гит с описанием того что было
изменено


Git и GitHub - гит это инструмент для контроля версий, а гитхаб платформа в интернете для работы с ним

git diff - Сравнивает рабочую папку и Индекс
git diff --staged - сравнивает индекс и последний коммит
